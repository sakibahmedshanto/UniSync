# UniSync
University Management System (UniSync) — a comprehensive platform designed to streamline administrative, academic, and library operations within a university environment. Built using Java, JavaFX, and MySQL, the system centralizes student, teacher, course, salary, payment, library, and activity management into dedicated role-based panels for Admins, Teachers, and Students.

Implemented a robust relational database architecture featuring stored procedures, triggers, cursors, joins, rollups, and constraint enforcement to ensure data integrity, automated validations, and efficient transaction handling. Advanced database mechanisms such as duplicate checks, auto-approval logic, role-based filtering, batch return processing, and soft-deletion tracking were incorporated to maintain consistency and operational reliability.

The system significantly reduces manual errors, improves data accessibility, enhances inter-stakeholder communication, and ensures secure, structured database management for institutional workflows.
